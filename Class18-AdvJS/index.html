Higher Order Functions & Map, Filter, Reduce

What is a Higher-Order Function?

A Higher-Order Function (HOF) is a function that either:

  • Takes another function as an argument
  • OR returns a new function
function greet(name) {
    return "Hello " + name;
}

function higherOrder(fn) {
    return fn("Ashar");
}

console.log(higherOrder(greet));

map()

map() is used to transform each element of an array and returns a new array.

const numbers = [1, 2, 3, 4];
const doubled = numbers.map(n => n * 2);
console.log(doubled);

filter()

filter() is used to filter elements based on a condition.

const numbers = [1, 2, 3, 4, 5];
const even = numbers.filter(n => n % 2 === 0);
console.log(even);

reduce()

reduce() is used to reduce an array to a single value (sum, total, etc.).

const numbers = [1, 2, 3, 4];
const sum = numbers.reduce((acc, curr) => acc + curr, 0);
console.log(sum);
