Callback & Callback Hell

Callback

A callback is a function passed as an argument to another function and executed later.

function greet(name, callback) {
  console.log("Hello " + name);
  callback();
}

greet("Ali", () => {
  console.log("Welcome!");
});

Callback Hell

Callback Hell occurs when multiple callbacks are nested inside each other, making code unreadable.

getUser(() => {
  getPosts(() => {
    getComments(() => {
      console.log("Done");
    });
  });
});
Problems:
  • Hard to read
  • Hard to debug
  • Hard to maintain
Solution:

Use Promises or Async/Await
