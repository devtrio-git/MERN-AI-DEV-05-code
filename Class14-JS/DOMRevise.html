🌳 DOM Manipulation in JavaScript

DOM (Document Object Model)
English: DOM is a tree-like structure created by the browser from your HTML code. JavaScript uses it to access, change, or delete HTML elements.
Urdu: Jab HTML page load hota hai, browser usko ek tree structure mai convert karta hai jise DOM kehte hain. JavaScript isi DOM ke zariye elements ko read, change, ya add kar sakti hai.

🎯 Common DOM Methods

  • getElementById() → Select element by ID
  • getElementsByClassName() → Select all elements with same class
  • querySelector() → Select first element by CSS selector
  • innerText / textContent → Change or get text
  • innerHTML → Change HTML inside an element
  • style.property → Change CSS style
  • createElement() → Create new HTML element
  • appendChild() → Add new element inside another
  • removeChild() → Remove a child element
  • value → Get value from input field
