📦 JavaScript Objects & 💾 Browser Storage in JavaScript

🧠 What is an Object in JavaScript?

English: An Object in JavaScript is a collection of key-value pairs. Each key (called a property) stores some value like text, number, or another object.

Urdu: JavaScript mai Object ek box jesa hota hai jisme hum key-value pairs mai data store karte hain. Har key ek property hoti hai jisme value hoti hai (text, number, ya object).

🔹 Example 1: Simple Object

// JavaScript Object
const student = {
  name: "Ali",
  age: 20,
  course: "Web Development"
};

// Accessing values
console.log(student.name);  // Output: Ali
console.log(student.age);   // Output: 20

🛠️ Example 2: Object with Function (Method)

const person = {
  firstName: "Ashar",
  lastName: "Ahmed",
  fullName: function() {
    return this.firstName + " " + this.lastName;
  }
};

console.log(person.fullName()); // Output: Ashar Ahmed
Urdu Explanation: Jab hum object ke andar function likhte hain to use "method" kehte hain. Yahan `fullName()` ek method hai jo `this` keyword se apne object ke data ko access kar raha hai.

🧠 What is an Browser Storage in JavaScript?

English:
Browser Storage means storing data inside the user’s web browser.
There are mainly two types of browser storage:
  • localStorage – Permanent (data stays even after page reload or browser close)
  • sessionStorage – Temporary (data clears when the tab is closed)
Urdu:
Browser Storage ka matlab hai ke hum apna data user ke browser ke andar store kar sakte hain.
Do main types hoti hain:
  • localStorage – Data permanently save rehta hai, browser band hone ke baad bhi.
  • sessionStorage – Data sirf tab tak rehta hai jab tak tab open hai, tab band hote hi delete ho jata hai.

🔍 Difference Between localStorage and sessionStorage

Feature localStorage sessionStorage
Data Lifetime Stays permanently (until manually cleared) Clears when tab is closed
Storage Limit Around 5–10 MB Same (5–10 MB)
Scope Accessible from all tabs of same domain Only accessible in same browser tab
Use Case Login tokens, theme preference, saved data Temporary forms, tab-specific info
Summary:
✅ localStorage: Permanent storage (data stays until cleared).
⏳ sessionStorage: Temporary storage (clears when tab closes).
🔠 Use JSON.stringify() to save objects as text.
🔄 Use JSON.parse() to convert back to object.

Urdu:
localStorage permanent data save karta hai, jabke sessionStorage tab close hone ke baad delete ho jata hai. Objects save karne ke liye unhe string mai convert karte hain using JSON.stringify(), aur load karte waqt wapas object mai badalte hain using JSON.parse().
